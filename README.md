# Умный список дел (Smart Todo List)

Простое консольное приложение на C++ для управления задачами.

## 🚀 Функции

- ✅ Добавление новых задач
- ✅ Просмотр всех задач
- ✅ Отметка задач как выполненных
- ✅ Удаление задач
- ✅ Фильтрация по статусу (активные/выполненные)
- 📊 Статистика выполнения

## 🛠 Компиляция и запуск

### В VS Code:
1. Откройте папку проекта в VS Code
2. Нажмите `Ctrl+Shift+B` для компиляции
3. Нажмите `F5` для запуска и отладки

### В терминале:
```bash
g++ -std=c++17 main.cpp TodoList.cpp -o todo_app
./todo_app
